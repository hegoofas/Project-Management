# 📊 Project Management Dashboard (Power BI)

A fully interactive and professionally designed Project Management Dashboard built using Power BI, delivering complete visibility into project performance, ROI, costs, risks, and timelines across departments and regions.

## 🚀 Project Overview
This dashboard provides a comprehensive view of project performance by integrating financial, operational, and timeline data.  
The report helps management quickly assess ROI, track project phases, monitor regional progress, and explore detailed project-level insights.

## 🛠 Steps Completed
### 1. Data Cleaning & Preparation
- Validated all input files and handled missing data  
- Fixed inconsistent data types  
- Removed duplicates and performed quality checks  

### 2. Data Modeling
- Built a clear and scalable data model  
- Added a Custom Date Table for time-intelligence functions  

### 3. DAX Measures
Created several key measures, including:  
- ROI (Return on Investment)  
- Benefit-to-Cost Ratio  
- Year-over-Year (YoY) Growth  
- Total Cost / Total Benefit  
- Active vs Completed Projects  

## ⚡ Power BI Features Used
- Interactive Slicers (Year, Status, Region)  
- Drill-through pages  
- Navigation Buttons for seamless report flow  
- KPIs & Cards  
- Conditional Formatting for performance and risk indicators  
- Multiple visualizations:  
  - Line Chart  
  - Bar & Column Charts  
  - Donut Chart  
  - Detailed Project Tables  

## 📊 Dashboard Highlights
### Overview
- Distribution of projects by department  
- Key KPIs (ROI, Total Cost, Total Benefit)  

### Regional Performance
- Projects by Status across regions  
- Regional comparison charts  

### Timeline & Risks
- Projects segmented by phases  
- Risk-level visualizations  

### Project Details
Detailed table containing:  
- Project Name  
- Cost & Benefit  
- ROI  
- Status  
- Region  
- Start & End Dates
